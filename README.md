# F☆☆KUN

**DON'T FAKE IT.**

F☆☆KUNのキャラクターイントロと、ブラウザ内で育てられるインタラクティブ・ピクセルペットを融合した公式Webプロトタイプです。

## Features

- Cinematic boot intro / scroll reveal / ambient pixel starfield
- Canonical 14×29 logical-pixel F☆☆KUN model rendered on Canvas
- Interactive PET ROOM: Feed / Pet / Play / Sleep / Daily Star
- FOOD / LOVE / ENERGY / ★ economy
- Real-time state decay and sleep recovery
- `localStorage` persistence across visits
- Local time based room lighting
- Optional WebAudio micro-SFX
- iPhone-first responsive UI; no framework, no build step
- GitHub Pages compatible static architecture

## Run

Open `index.html` directly, or serve the repository with any static server.

## GitHub Pages

Repository Settings → Pages → Deploy from a branch → `main` / root (`/`).

## Character direction

F☆☆KUN is a rebellious, deadpan street character built around the idea: **BE YOURSELF. DO YOUR BEST. F☆☆K THE REST.**
